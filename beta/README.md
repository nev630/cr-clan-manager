## ⚡ v1.8.2 120fps 슬라이딩 탭 필 & 상시 마운트 양방향 스프링 팝업 & GPU 시상대 애니메이션 전면 고도화 (Ultra-Smooth 120fps Animation Engine)

1. **탭 전환 슬라이딩 필(Segmented Pill) & 실키 뷰 글라이드 탑재 (`index.html`, `css/style.css`, `js/app.js`)**:
   - 상단 메인 탭(**내 클랜 대시보드** ↔ **타 갤클과 비교**)과 비교 지표 탭(**총 지원량** ↔ **1인 평균**)에 GPU 하드웨어 가속(`transform: translate3d`)으로 부드럽게 미끄러지는 슬라이딩 배경 필(`.segmented-pill`)을 적용했습니다.
   - 탭 전환 시 `behavior: 'smooth'` 스크롤과 차트 파괴가 한 프레임에 겹치며 끊기던 문제를 해결하고, 전환되는 뷰 전체가 `tabViewGlideIn`(`cubic-bezier(0.16, 1, 0.3, 1)`)으로 물 흐르듯 부드럽게 올라오도록 개선했습니다.
2. **상시 마운트(Pre-composited) 기반 양방향 120fps 팝업 모달 스프링 트랜지션 (`index.html`, `css/style.css`, `js/app.js`)**:
   - 기존의 `display: none`(`hidden`) 즉시 토글로 인해 팝업 오픈 첫 프레임에서 `backdrop-filter` 초기화 레이아웃 스래싱이 발생하고 닫힐 때는 애니메이션 없이 뚝 사라지던 문제를 해결했습니다.
   - 모든 팝업(`#dormant-members-modal`, `#member-detail-modal`, `#sync-error-modal`)을 `.modal-overlay` 상시 마운트 레이어로 유지하고 `openModalSmooth()` / `closeModalSmooth()`를 통해 열릴 때와 닫힐 때 모두 120fps 스프링 곡선(`translate3d` + `scale3d` + `opacity`)으로 부드럽게 개폐됩니다.
   - '3일+ 미접속 대상자' 팝업에서 클랜원을 누르면 미접속 팝업이 스르륵 닫히며 상세 모달로 매끄럽게 이어지는 교차 전환(`switchFromDormantToMember`)을 적용했습니다.
3. **시상대(Podium) 단상 애니메이션 100% GPU `scaleY` 전환 & 도넛 차트 비파괴 리플레이 (`css/style.css`, `js/app.js`)**:
   - 매 프레임 브라우저 Layout Reflow를 유발하던 `height: 0 -> 7rem` 키프레임을 제거하고, `transform-origin: bottom center` 기반의 `scale3d(1, 0.08, 1) -> scale3d(1, 1, 1)`(`@keyframes podiumScaleRise`)로 전면 교체하여 레이아웃 재계산 비용을 0으로 줄였습니다.
   - 대시보드 탭 복귀 시 도넛 차트 인스턴스를 파괴(`destroy()`)하고 재생성하던 무거운 연산을 제거하고, 기존 캔버스를 유지한 채 `reset() + update()`로 회전 애니메이션만 부드럽게 재생합니다.
4. **캐시 버스팅 파라미터 갱신 (`index.html`)**:
   - 스타일시트, API 클라이언트, 앱 스크립트 참조 쿼리 파라미터를 모두 `?v=1.8.2`로 동기화했습니다.

🏛️ 시스템 아키텍처 및 Oracle Cloud의 역할
본 프로젝트는 슈퍼셀(Supercell) 공식 API의 보안 정책과 고성능 실시간 처리를 위해 Oracle Cloud + Cloudflare Worker 하이브리드 아키텍처를 채택하고 있습니다.
Oracle Cloud의 핵심 역할
1. 슈퍼셀 공식 API 고정 IP 화이트리스트 통과:
   * 슈퍼셀 공식 개발자 포털은 API 키 발급 시 **인가된 고정 공인 IP(Static IP)**에서 들어오는 트래픽만 허용합니다.
   * 사용자 브라우저(동적 IP)나 일반 서버리스 환경(유동 IP)에서는 직접 호출이 불가능하므로, 고정 IP(168.110.63.115)가 제공되는 Oracle Cloud Always Free (도쿄/서울 리전) 전용 인스턴스가 슈퍼셀과 직접 통신하는 공식 관문 역할을 수행합니다.
2. API 보안 키(Token) 은닉 및 무단 유출 방지:
   * 클라이언트 브라우저에 개발자 토큰을 노출하지 않고, 오라클 서버 내부 환경변수(SUPERCELL_API_KEY)로 안전하게 보관하여 대행 인증합니다.
3. CORS (Cross-Origin Resource Sharing) 해결:
   * 웹 브라우저에서 공식 API 직접 호출 시 발생하는 보안 정책(CORS) 차단을 해소하기 위해 표준 허용 헤더를 부착하여 응답합니다.
4. 인메모리 On-Demand TTL 캐시 & 통합 단일 요약 엔드포인트 (/summary):
   * 클랜원 50명의 개별 배틀로그 조회를 클라이언트가 각각 호출할 경우 발생하는 429(Rate Limit) 병목을 방지하기 위해, 오라클 프록시 서버(server.js)에서 50명의 데이터를 한 번에 번들링하여 0.1초 만에 응답하는 통합 엔드포인트를 제공합니다.

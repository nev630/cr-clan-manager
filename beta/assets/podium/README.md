# 에셋(PNG) 업로드 가이드 (GitHub Pages 배포용)

이 폴더(`assets/podium/`)에 아래 3개의 PNG 파일을 업로드하시면 시상대 상단 1~3위 킹 석상 이미지가 즉시 적용됩니다.

- `assets/podium/king-gold.png` : 1위 황금 킹 석상 (투명 배경 PNG 권장)
- `assets/podium/king-silver.png` : 2위 은색 킹 석상 (투명 배경 PNG 권장)
- `assets/podium/king-bronze.png` : 3위 동색 킹 석상 (투명 배경 PNG 권장)

※ 파일이 아직 업로드되지 않았거나 경로가 다를 경우에도 깨진 이미지 아이콘 없이 내장된 금/은/동 킹 석상 벡터 그래픽이 자동으로 표시됩니다.

# Loading Screen Assets (`beta`)

이 폴더에 아래 두 이미지를 업로드하면 베타 대시보드 로딩 화면에 자동으로 적용됩니다.

1. **초기 중앙 로고 (슈퍼셀 로고 자리)**
   - 파일명: `intro-logo.png` (`.webp`, `.jpg`, `.jpeg`, `.svg` 모두 지원)
   - 검은 배경 중앙에서 반짝이며 등장합니다. (투명 배경 PNG 권장)

2. **로딩 아트워크 배경**
   - 파일명: `artwork.png` (`.webp`, `.jpg`, `.jpeg` 모두 지원)
   - 로고 등장 직후 화면 전체에 표시되며, 하단에 인게임 스타일 로딩 바와 랜덤 `TIP` 문구가 함께 표시됩니다.

# 클랜 관리 대시보드

클래시 로얄(Clash Royale) 클랜 Good Fellas (`#G890J9JC`)의 클랜원 활동성 모니터링 및 운영을 위한 실시간 웹 대시보드입니다.

---

## 주요 기능

- **주간 지원 Top 7 올림픽 단상**: 지원 기여도가 가장 높은 멤버 시각화
- **클랜 핵심 지표**: 전체 클랜원 수, 공식 주간 총 지원량, 장기 미접속자 현황
- **최근 접속 분포 차트**: 오늘 / 1~2일 전 / 3일 이상 미접속 비율 도넛 차트 제공
- **스마트 검색 & 필터**: 닉네임·태그 실시간 검색, 3일+ 미접속 및 지원 저조자 원클릭 필터링
- **모바일 & PC 반응형 UI**: 스마트폰에서도 한 손으로 쾌적한 2분할 고밀도 카드 뷰
- **초고속 실시간 동기화**: 단일 API 호출을 통한 0.5초 이내 실시간 데이터 갱신

---

## 기술 스택

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3, Tailwind CSS
- **Proxy**: Cloudflare Workers
- **Hosting**: GitHub Pages
